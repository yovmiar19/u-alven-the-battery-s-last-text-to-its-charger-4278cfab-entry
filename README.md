A make.fun entry: one line of at most 200 characters — the phone battery's
final message to the charger it waited for all day.

> "I dimmed my screen for you, turned off Bluetooth for you, killed every
> app for you. And you were in the car the whole time."

`main.ts` writes exactly that line to `/output/entry.txt` (UTF-8), checks it
against the 1–200 character gate, and reads the file back to verify the
bytes on disk match the line exactly.
